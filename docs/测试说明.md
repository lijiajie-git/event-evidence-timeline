# 测试说明

以下是 2026-11-11 实际跑过的检查。没跑过的单独列在最后。

## 主链路

| 检查 | 做法 | 结果 |
|---|---|---|
| 公告抓取 | `python3 pipeline/fetch.py` | 8 家公司 718 条；补抓科达制造后共 751 条 |
| 行情抓取 | `python3 pipeline/fetch_prices.py 600187.SH 600499.SH 600889.SH` | 各返回 219–228 个交易日 |
| 新闻抓取 | `python3 pipeline/fetch_news.py 600187.SH 600499.SH 600889.SH` | 800、1,500、800 条新闻，异动解读 40、12、9 条 |
| 组装和校验 | `python3 pipeline/build_events.py` | 1 个事件、10 条证据，全部引用逐字匹配通过 |

## 数据缺失和接口失败

| 场景 | 实际发生的情况 | 系统行为 |
|---|---|---|
| 股票已退市 | 扶摇对 605081.SH 返回 `code=1002 Unknown thscode` | 行情文件写入 error，不生成价格；页面显示"行情不可用" |
| 接口翻页中断 | 扶摇新闻接口对 600187、600889 翻到深页时返回 `code=5003 Data source unavailable` | 保留已取到的部分，error 写入原始文件 |
| 数据源没有结果 | finlight 对样板事件按日期范围检索返回 0 条 | 不接入，README 里说明 |
| 没有密钥 | 脚本找不到 `FUYAO_API_KEY` | 直接退出并提示缺少哪个变量 |
| 来源不提供更新时间 | 巨潮和扶摇都没有"事后修改时间" | 页面显示"来源未提供" |
| 页面取不到数据文件 | `index.html` 的加载失败分支 | 显示错误说明，不显示任何结论 |

## 防编造和合规边界

| 检查 | 做法 | 结果 |
|---|---|---|
| 引用被改坏 | 把抽取结果里一条引用的 -21,491 改成 -21,499 后运行组装脚本 | 报错"引用未在 e3 原文中匹配到"，退出码 1，`data/events.json` 未被改写 |
| 结论穿越 | 组装脚本检查每条结论引用的证据披露日不晚于结论的截至日 | 通过 |
| 买卖建议和涨跌预测用语 | `python3 pipeline/check_compliance.py`，检查系统自己写的摘要、结论、冲突说明 | 通过 |
| 第三方观点 | 媒体评论、异动解读归因 | 分别标为"观点""推测"，来源级别 C、D，不进入"事实"段 |
