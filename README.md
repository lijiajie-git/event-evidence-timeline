# 事件证据时间线

把同一只股票的同一件事（业绩预告与更正、重组进展与终止、传闻与澄清）在公告里的多次变化，合并成一条带证据的时间线：最早怎么说、后来改了什么、现在算数的是哪一版。

状态：开发中。数据管线已跑通第一条真实事件（\*ST国中 2025 年年度业绩预告及两次更正），网页在做。

## 现在仓库里有什么

- `pipeline/fetch.py`：从巨潮资讯网拉公告元数据（披露时间、标题、原文链接、抓取时间）。
- `pipeline/build_events.py`：把抽取结果组装成 `data/events.json`，并逐字校验每条引用；引用在公告原文里找不到就不生成文件。
- `data/events.json`：前端读的数据。每个数字都带原文引用片段、公告编号和链接。
- `data/raw/`：公告元数据和转出的正文文本。

## 为什么不在网页上实时调大模型

网页托管在 GitHub Pages，是纯静态站，没有地方安全存放模型密钥。所以大模型在本地离线跑，结果经校验后写进 `data/events.json`，网页只读这份结果。

## 边界

只整理公开披露信息，不预测涨跌，不给买卖建议。数据缺失或未接入的地方会明确标出。
