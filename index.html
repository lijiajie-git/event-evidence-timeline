    02 / 亮点

    每一步是规则还是模型做的，核了什么，都留了记录

    模型只做读不懂就做不准的部分：抽说法、抽数字、判断是不是同一件事、写分时点结论。抓取、分级、状态、时间和全部校验都是规则；任何一条引用对不上原文，这次就不生成数据文件。

    03 / 评测

    抽得准不准：独立标注的标准答案，加上故意改坏数据的陷阱

    标准答案由另一个窗口在不看抽取结果的情况下标注，是模型标的，不是人工标的；能逐字核对原文的部分已经自查。主数字是每个事件第一次抽取、还没参考评测意见时的成绩；按评测意见改过之后的分数放在后面，那些不是独立测量。陷阱用例是把数据故意改坏，看管线拦不拦得住。数字都直接读 eval/report.json。

    边界

    网页不实时调模型，也不给买卖建议

    为什么网页不实时调模型

    页面托管在 GitHub Pages，是纯静态站，没有地方安全存放模型密钥。所以模型在本地跑，结果经过校验再发布；问答是离线生成的预置问题，每一步推理都留了记录。

    你自己输入的话，页面只做两件事：读出数字和已收录的版本比对，或者找最接近的预置问题。都对不上就直说。

    边界

    只整理公开披露的公告和公开报道。不预测涨跌，不给买卖建议。事实、推断、不确定分开写；每个数字都能点回原文。

    没接入或没抽取的地方标成“未接入”“未抽取”，不显示成正常值。
