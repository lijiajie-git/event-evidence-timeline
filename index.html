    04 / 流程与边界

    模型只做读不懂就做不准的部分

    1. 规则抓取巨潮公告、扶摇新闻和异动解读、日 K 线。记下披露时间和抓取时间。
    2. 模型 · 离线抽取说法、数字、类型（事实/观点/推测/传闻）、谁更正了谁，每条带原文引用。
    3. 规则校验引用逐字匹配原文；时序检查；合规词检查。不通过就不生成文件。
    4. 规则组装来源分级和权重、状态、版本有效期、冲突、分时点结论。
    5. 网页只读页面读 data/events.json，回放、查验都在浏览器里算。

    为什么网页不实时调模型

    页面托管在 GitHub Pages，是纯静态站，没有地方安全存放模型密钥。所以模型在本地跑，结果经过校验再发布；问答是离线生成的预置问题，每一步推理都留了记录。

    你自己输入的话，页面只做两件事：读出数字和已收录的版本比对，或者找最接近的预置问题。都对不上就直说。

    边界

    只整理公开披露的公告和公开报道。不预测涨跌，不给买卖建议。事实、推断、不确定分开写；每个数字都能点回原文。

    没接入或没抽取的地方标成“未接入”“未抽取”，不显示成正常值。
